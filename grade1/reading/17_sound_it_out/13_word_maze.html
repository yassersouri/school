📝 Parent note: The maze on page 1 has multiple valid paths through the green cells — here is one simple route: START → NAP·KIN → PIC·NIC → RAB·BIT → HEL·MET → MAG·NET → HOT·DOG → JACK·POT → MUF·FIN → PUM·KIN → SAND·BOX → BOB·CAT → END. (Another shorter route: START → NAP·KIN → PIC·NIC → HEL·MET → MAG·NET → JACK·POT → SAND·BOX → BOB·CAT → END.) The point isn't a single “right” path — it's that the child reads each cell aloud and judges real-vs-silly before stepping. The Silly Word Giggle box at the bottom is intentional decoding practice: nonsense words prove the child can apply chunking blindly, not just rely on memory of known words.
