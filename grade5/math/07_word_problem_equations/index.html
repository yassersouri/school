Learn the building blocks, then master 5 classic challenge puzzles

🗺️ How this works: Lessons 1–7 build the foundation skills one at a time (equations, ratios, two-unknown puzzles, surplus/shortfall, patterns). Lessons 8–12 are challenge sets — each one has 4 practice versions of a classic puzzle type so you can practice until it clicks. Lesson 13 mixes everything together in 3 full review versions.
