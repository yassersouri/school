# Print-ready worksheets for Math and Reading

<https://yassersouri.github.io/school>

Mostly AI-generated.

## 🎮 Interactive activities

Besides the printable sheets, each grade has an **Interactive** section (`gradeN/interactive/`)
with on-screen games and explorers for math and reading — tap, drag, and listen (words, numbers and
stories are read aloud with the browser's built-in text-to-speech). These pages are meant for a
computer or tablet and are not printable. Progress (stars) is saved in the browser.

Shared toolkit: [`assets/interactive/`](assets/interactive/README.md). Run locally with `./host.sh`.
