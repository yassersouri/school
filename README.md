# Print-ready Math and Reading Practice

<https://yassersouri.github.io/school>

This repository contains printable practice material for Grade 1 reading and
math and selected Grade 5 math topics. Use the subject indexes and syllabi to
choose a sheet that matches the learner's current skill:

- [Grade 1 reading syllabus](grade1/reading/syllabus.md)
- [Grade 1 math syllabus](grade1/math/syllabus.md)
- [Grade 5 math learning path](grade5/math/syllabus.md)

## How to use the sheets

1. Teach or review the idea before assigning independent practice.
2. Start with a small set of questions and ask the learner to explain one
   answer. Accuracy and understanding matter more than speed.
3. Use the answer key for feedback, not just scoring. Re-teach a concept when
   errors follow a pattern.
4. Stop or switch activities if the vocabulary, reading load, or number range
   is not yet accessible.

The Grade 1 syllabi describe a broad Canadian learning sequence, not a promise
that every curriculum expectation has a worksheet. Adapt regional vocabulary,
currency, spelling, pacing, and expectations as needed.

## Material quality standard

Much of the material began as AI-generated drafts. Every sheet should therefore
be reviewed by an adult before use. A useful sheet must:

- state one clear, age-appropriate learning goal;
- practise only skills already introduced, except for clearly marked challenge
  items;
- use familiar, inclusive, and unambiguous language;
- progress from a model or supported item to independent practice;
- provide enough space to work and remain readable when printed;
- include an accurate answer key for questions with fixed answers;
- avoid trick questions, unsafe scenarios, and vocabulary chosen only to fit a
  spelling pattern;
- use consistent mathematical and literacy terminology.

These resources supplement instruction; they are not a complete curriculum or
a diagnostic assessment.
